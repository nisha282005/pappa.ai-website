# Pappa.ai Official Website

Official website for Pappa.ai — the modern school management platform.

## Tech Stack
- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4 + Design System tokens
- **Routing:** React Router v7
- **Icons:** Lucide React
- **Typography:** Plus Jakarta Sans

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
