# Hero carousel videos

Drop one clip per role and theme here. File names must match `src/data/heroSlides.js`:

student-light.mp4  student-dark.mp4
teacher-light.mp4  teacher-dark.mp4
parent-light.mp4   parent-dark.mp4
admin-light.mp4    admin-dark.mp4

- Length: about 4 seconds. The slide moves to the next one when the clip ends.
- Size: 1920x1080 (16:9), H.264 MP4, no audio track, ideally under 2 MB each.
- Keep the left ~40% of the frame calm (no text, no busy detail): the headline sits there.
- Don't bake text, cards or app badges into the video; the page draws those.
- Missing files are fine: the slide shows its poster image instead.
